FIRST-RUN CHECKLIST
A fresh machine needs ComfyUI plus every checkpoint JARVIS generates with. Work top to bottom:
1 — Install and start ComfyUI (Desktop or portable), then start this server so the guide can see it.
2 — Create a free Hugging Face account, accept the Krea 2 / MiniMax H3 model licenses, create a read access token, paste it below.
3 — Download missing models (large — 60 GB+ total; leave it running).
4 — Install missing custom nodes, then restart ComfyUI.
Green means ready: image, video, upscale and edit each light up below.
HUGGING FACE TOKEN
Needed for gated repos (Krea 2, MiniMax H3). Get one at huggingface.co → avatar → Settings → Access Tokens → New token (read). Accept each model's license on its repo page first.

Off = no noise injection.

VIDEO GENERATION (MiniMax H3)

                            
Blank = use default. Changes save on Enter / blur.

                        

                            
                            
                            Default: minimax_h3_fl2va_pruned_int8_convrot.safetensors (T2VA). Pick minimax_h3_ref2va_pruned_int8_convrot.safetensors for image-to-video.
                        

                        

                            
                            
                            Default: qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors. Must match the UNET variant (nvfp4 for int8 UNETs, nvfp8 for fp16).
