SETTINGS General
FIRST-RUN CHECKLIST
A fresh machine needs ComfyUI plus every checkpoint JARVIS generates with. Work top to bottom:
1 — Install and start ComfyUI (Desktop or portable), then start this server so the guide can see it.
2 — Create a free Hugging Face account, accept the Krea 2 / MiniMax H3 model licenses, create a read access token, paste it below.
3 — Download missing models (large — 60 GB+ total; leave it running).
4 — Install missing custom nodes, then restart ComfyUI.
Green means ready: image, video, upscale and edit each light up below.
HUGGING FACE TOKEN
Needed for gated repos (Krea 2, MiniMax H3). Get one at huggingface.co → avatar → Settings → Access Tokens → New token (read). Accept each model's license on its repo page first.

ENGINE

                            

                                
                                
                                
                            

                            
                            RTX is video-only and always scales by the Multiplier (images fall back to SeedVR2). SeedVR2 handles images and video; Ultimate SD is image-only. Both use the Mode setting below.
                        

                        

                            
SCALE

                            

                        

                            
                            
                        

                        

                            
                            
                            Target short-side resolution for SeedVR2 and Ultimate SD.
                        

                        

                            
                            
                            RTX scale factor, or the source scale for SeedVR2/Ultimate SD in Multiplier mode.
                        

                            

                            

                                4x RTX video upscale scales both sides by 4 (16x the pixels), so VRAM use and the downloaded file size rise sharply. Video upscales also hold the full source and output in system RAM. Lower the multiplier if ComfyUI runs out of memory.
                            

                        

                        

                            SEEDVR2 DETAILS
                            

                        

                            
                            
                            Sharp uses the 7B-sharp DiT variant (wavelet color correction). Balanced uses lab color correction.
                        

                        

                            
                            
                            Input noise level for detail synthesis. Off = no noise injection.
                        

                        

                            
                            
                        

                        

                            
                            
                            Sharp profile uses seedvr2_ema_7b_sharp_fp8_e4m3fn_mixed_block35_fp16.safetensors when installed.
                        

                        

                            
                            
                        

                        

                            
                            
                            Default: sdpa. Options: sdpa, sageattn_2, sageattn_3, flash_attn_2, flash_attn_3 (NVIDIA only).
                        

                            

                        

                        

                            One shared upscale for images and video. Ask JARVIS to "upscale this image" or "upscale this video" and it will upscale the last generated one in the conversation.
                        

                        

                            
                        

                    


                    
                    

                        

                            
VIDEO GENERATION (MiniMax H3)

                            
Blank = use default. Changes save on Enter / blur.

                        

                            
                            
                            Default: minimax_h3_fl2va_pruned_int8_convrot.safetensors (T2VA). Pick minimax_h3_ref2va_pruned_int8_convrot.safetensors for image-to-video.
                        

                        

                            
                            
                            Default: qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors. Must match the UNET variant (nvfp4 for int8 UNETs, nvfp8 for fp16).
                        

                        

                            
                            
                            Default: minimax_h3_video_vae_fp16.safetensors
                        

                        

                            
                            
                            Default: minimax_h3_audio_vae_fp32.safetensors
                        

                        

                        

                            
OUTPUT

                            

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                            Auto picks the best backend ComfyUI offers: Comfy Kitchen attention (built into ComfyUI v0.32+) first, then SageAttention, else dense PyTorch attention. Choose one explicitly to force it.
                        

                            

                        

                        

                            
MINIMAX H3 TURBO

                            
Use the MiniMax H3 Turbo LoRA for faster 4–8 step generation.

                        

                            
                            Off keeps the normal H3 workflow unchanged. On routes the model through the Turbo LoRA and Turbo sampler (strength 1.0, simple scheduler).
                        

                            

                        

                            
                            
                            6–8 steps generally provide better quality. 4 steps is fastest but may show motion smearing during fast motion.
                        

                        

                            
                            
                            Place the LoRA in ComfyUI models/loras. Default: minimax_h3_turbo_v4_step600_ema.safetensors
                        

                            

                        

                        

                            
FIRST BLOCK CACHE

                            
Optional MiniMax H3 MODEL patch that reduces redundant transformer computation. Higher cache aggressiveness can change the denoising trajectory.

                        

                            
                            Needs the ComfyUI-MiniMaxH3-FirstBlockCache custom node. First enable auto-installs it (restart ComfyUI when it finishes). Composes with the attention backend and Turbo LoRA; applies to MiniMax H3 only.
                            
                        

                            

                        

                            
                            
                            Named presets keep their calibrated values. Manual values only apply in Custom mode.
                        

                            

                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                        

                            
                            Also checks the most changed target-video latent frame, catching local motion a global average hides.
                        

                            

                            

                        

                            
                            
                        

                        

                            

                        

                        

                        

                            
FACE REFINEMENT

                            
Optional second H3 pass after each video: tracks faces per frame, re-generates them at low denoise, stitches them back. Fixes small/distant faces.

                        

                            
                            Runs automatically after every video. First enable auto-installs the ComfyUI nodes + face detector (restart ComfyUI when it finishes).
                        

                            

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                            

                            

                        

                            
                            
                        

                        

                            
                            
                        

                            

                        

                            
                            
                            Ultralytics face model in ComfyUI models/ultralytics/bbox/.
