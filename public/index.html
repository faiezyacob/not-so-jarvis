SETTINGS General
FIRST-RUN CHECKLIST
A fresh machine needs ComfyUI plus every checkpoint JARVIS generates with. Work top to bottom:
1 — Install and start ComfyUI (Desktop or portable), then start this server so the guide can see it.
2 — Create a free Hugging Face account, accept the Krea 2 / MiniMax H3 model licenses, create a read access token, paste it below.
3 — Download missing models (large — 60 GB+ total; leave it running).
4 — Install missing custom nodes, then restart ComfyUI.
Green means ready: image, video, upscale and edit each light up below.
HUGGING FACE TOKEN
Needed for gated repos (Krea 2, MiniMax H3). Get one at huggingface.co → avatar → Settings → Access Tokens → New token (read). Accept each model's license on its repo page first.
CIVITAI TOKEN
Needed to download the BFS Character Swap LoRA used by H3 Recast. Create an API key at civitai.com → Account settings → API Keys, then paste it here. The key is only used for Civitai model downloads.

IMAGE MODEL

                            
Choose which text-to-image pipeline the BASE MODELS below feed.

MiniMax H3 Image uses 4/6/10/16 MP for S/M/L/XL; Qwen, Krea and MOSS-Image use 0.75/1/1.25/1.75 MP.

Turn it off to send the prompt exactly as written.

IMAGE EDIT

                            
Which pipeline edits an existing image (and character/scene references).

                            

                                
                                
                                Qwen Image Edit (default) is a native instruction editor that accepts several reference images addressed by position. Krea 2 Identity Edit is a reference-guided edit that preserves a subject's identity — it needs the Krea 2 base models, the Identity Edit LoRA and the comfyui-krea2edit node pack (Setup), and it uses at most one extra reference image. MiniMax H3 Image Edit is a reference-guided instruction editor that shares the MiniMax H3 Image models; it keeps the source composition at a configurable megapixel budget. MOSS-Image Edit uses the dedicated edit LoRA and ComfyUI's MOSS-Image Edit text encoders (ComfyUI 0.43.0+); describe only the change and keep the source aspect ratio.
                                

                                    
                                    
                                    Pixel budget the MiniMax editor resizes the source to (0.5–16 MP). Lower is faster and safer on 16 GB VRAM.
                                

                                

                                    
                                    
                                    Pixel budget the MOSS editor scales the source to (0.25–4 MP, default 1). The output keeps the source aspect ratio and a 16 px grid.

ENGINE

                            

                                
                                
                                
                            

                            
                            SeedVR2 is the default: a diffusion upscaler that gives the best quality for images and video. RTX is a fast single-pass video super-resolution (softer); images fall back to SeedVR2. Ultimate SD is image-only. RTX and SeedVR2 use the Mode setting below so every source can land on the same output size.
                        

                        

                            
SCALE

                            

                        

                            
                            
                        

                        

                            
                            
                            Target short-side resolution for RTX and SeedVR2. The source aspect ratio is kept, so 2160p is 3840×2160 for 16:9, 2160×3840 for 9:16 and 2160×2160 for square, regardless of the initial resolution.
                        

                        

                            
                            
                            Scale factor for RTX in Multiplier mode, or the source scale for SeedVR2/Ultimate SD in Multiplier mode.
                        

                            

                            

                                4x RTX video upscale scales both sides by 4 (16x the pixels), so VRAM use and the downloaded file size rise sharply. Video upscales also hold the full source and output in system RAM. Lower the multiplier if ComfyUI runs out of memory.
                            

                        

                        

                            SEEDVR2 DETAILS
                            

                        

                            
                            
                            Sharp uses the 7B-sharp DiT variant (wavelet color correction). Balanced uses lab color correction.
                        

                        

                            
                            
                            Input noise level for detail synthesis. Off = no noise injection.
                        

                        

                            
                            
                        

                        

                            
                            
                            Sharp profile uses seedvr2_ema_7b_sharp_fp8_e4m3fn_mixed_block35_fp16.safetensors when installed.
                        

                        

                            
                            
                        

                        

                            
                            
                            Default: sdpa. Options: sdpa, sageattn_2, sageattn_3, flash_attn_2, flash_attn_3 (NVIDIA only).
                        

                            

                        

                        

                            One shared upscale for images and video. Ask JARVIS to "upscale this image" or "upscale this video" and it will upscale the last generated one in the conversation.
                        

                        

                            
                        

                    


                    
                    

                        

                            
VIDEO GENERATION (MiniMax H3)

                            
Blank = use default. Changes save on Enter / blur.

                        

                            
                            
                            Default: minimax_h3_fl2va_pruned_int8_convrot.safetensors. Used for both text-to-video and image-to-video (H3 animates a single first frame).
                        

                        

                            
                            
                            Default: qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors. Must match the UNET variant (nvfp4 for int8 UNETs, nvfp8 for fp16).
                        

                        

                            
                            
                            Default: minimax_h3_video_vae_int8_convrot.safetensors
                        

                        

                            
                            
                            Default: minimax_h3_audio_vae_fp32.safetensors
                        

                        

                        

                            
OUTPUT

                            

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                            Applied to normal, UGC and Creator Studio videos.

Choose one explicitly to force it.
                        

                            

                        

                        

                            
SAMPLING

                            
H3 diffusion steps and CFG guidance for standard (=15s) video. Double-click a value to reset it to the default.

                            

                                

                                    
                                    
                                

                                

                                    
                                    
                                    1 = unguided (default). Above 1 adds a negative-conditioning guidance pass.
                                

                            

                        

                        

                            
MINIMAX H3 TURBO

                            
Use the MiniMax H3 Turbo LoRA for faster 4–8 step generation.

                        

                            
                            On by default. Routes the model through the Turbo LoRA and Turbo sampler (strength 1.0, simple scheduler) at the model's native canvas for the recommended quality/speed path. Off keeps the full 25-step base workflow.
                        

                            

                        

                            
                            
                            6–8 steps generally provide better quality. 4 steps is fastest but may show motion smearing during fast motion.
                        

                        

                            
                            
                            Used for text-to-video and image-to-video. Place the LoRA in ComfyUI models/loras. Default: minimax_h3_turbo_v4_step600_ema.safetensors
                        

                            

                        

                        

                            
H3 CHARACTER SWAP

                            
Model-only LoRA used by @video character replacement: replace a person in an existing clip with the identity from an @image reference. Recommended checkpoint (Rigless v1) at strength 1.0.

                        

                            
                            On by default. Applied to the reference-to-video replacement graph. Turn it off to run on the stock Ref2VA base. Install the LoRA from Settings > Setup if it is missing.
                        

                            

                        

                            
                            
                            Place the LoRA in ComfyUI models/loras. Default: rigless-lora-v1.safetensors
                        

                        

                            
                            
                            1.0 is the recommended strength for the Rigless v1 adapter.
                        

                            

                        

                        

                            
FIRST BLOCK CACHE

                            
Optional MiniMax H3 MODEL patch that reduces redundant transformer computation. Higher cache aggressiveness can change the denoising trajectory.

                        

                            
                            Needs the ComfyUI-MiniMaxH3-FirstBlockCache custom node. First enable auto-installs it (restart ComfyUI when it finishes). Composes with the attention backend and Turbo LoRA; applies to MiniMax H3 only.
                            
                        

                            

                        

                            
                            
                            Named presets keep their calibrated values. Manual values only apply in Custom mode.
                        

                            

                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                        

                            
                            Also checks the most changed target-video latent frame, catching local motion a global average hides.
                        

                            

                            

                        

                            
                            
                        

                        

                            

                        

                        

                        

                            
CHARACTER REPLACEMENT · BACKGROUND

                            
For @video character replacement. Segments the target person with SAM3, tracks them across the clip, and composites the replacement back onto the original frames so the background and other people keep their original pixels. Optional; needs the SAM3 checkpoint in ComfyUI/models/checkpoints.

                            

                                
                                Off = the whole frame is regenerated and the background can drift. On = only the tracked person changes (tracks every frame; slower).
                            

                            

                                

                                    
                                    
                                

                                

                                    
                                    
                                

                            

                        

                        

                            
FACE REFINEMENT

                            
Optional second H3 pass after each video: tracks faces per frame, re-generates them at low denoise, stitches them back. Fixes small/distant faces.

                        

                            
                            Runs automatically after every video. First enable auto-installs the ComfyUI nodes + face detector (restart ComfyUI when it finishes).
                        

                            

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                            

                            

                        

                            
                            
                        

                        

                            
                            
                        

                            

                        

                            
                            
                            Ultralytics face model in ComfyUI models/ultralytics/bbox/.
                        

                        

                            
                            
                        

                        

                            

                        

                        

                        

                            
FRAME INTERPOLATION

                            
Optional post-process that raises the clip's frame rate by synthesising intermediate frames with RIFE. Doubling turns H3's 24 fps into a smoother 48 fps.

                        

                            
                            Runs automatically after every video (after Face Refinement, before Auto Upscale). Needs the ComfyUI-Frame-Interpolation custom node. First enable auto-installs it (restart ComfyUI when it finishes).
                        

                            

                        

                            
                            
                            2x turns 24 fps into 48 fps. Higher multipliers interpolate more frames and take longer.
                        

                        

                            
                            
                            RIFE checkpoint name. The checkpoint downloads on first use.
                        

                            

                        

                            
                            
                        

                        

                            

                        

                        

                        

                            
AUTO UPSCALE

                            
Run the video upscale pipeline on every generated video. The original clip is kept, so the gallery can compare them side by side.

                        

                            
                            Runs automatically after each video using the shared UPSCALE settings (engine, resolution, profile). Best-effort — a failed upscale keeps the base video.
                        

                        

                        

                            
H3 LATENT UPSCALE

                            
Generate at lower resolution, upscale the H3 latent, then refine at the target resolution. Faster than generating the full-resolution video directly, while retaining H3's temporal information. This saves time, not VRAM — the refinement still runs at the target resolution.

                        

                            
                            
                            Auto picks a scale from the requested output size — direct generation for small clips, 1.5×–3× for larger ones — and falls back to direct H3 when the upscaler is not installed. An explicit scale fails clearly if the model is missing. Off always generates directly at native resolution.
                            Requires the H3 Latent Upscaler ComfyUI node + a ~691 MB checkpoint. Press “Install / check” to install both (restart ComfyUI when done).
                            
                            
                        

                            

                        

                            
                            
                            Controls how aggressively the high-resolution refinement modifies the upscaled latent (0.1–0.8). It maps to the refinement pass's denoise (the fraction of the sampling schedule actually run). Default 0.35.
                        

                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                        

                            
                            Split long videos into temporal chunks to cap VRAM. Leave on unless the clip is short.
                        

                        

                            
                            Offload the upscaler model to CPU after inference to free VRAM for the refinement pass.

PEOPLE

                    

                        

                            
                            
                        

                        
Detect every person, then click the one to replace. SCAIL-2 tracks that person with SAM 3.1 and never replaces the others.

                        

                    

                    

                    

                    

                        
                        
                    

                    


                    

                    
TRACK & MASK

                    

                        
                        
                        
                        
                        
                    

                    

                        
                        
                    

                    

                        
                        
                        
                    

                    

                        
                        
                    

                    

                        
                        
                        
                        
                    

                    
Select: click the person (Shift-click excludes background). The tint is SAM's current mask — if it covers the scene, add exclude points. Track follows it through the clip. Brush/Eraser fix the tracked mask on the current frame. Keep Grow small (8–16); large growth paints a generated halo around the subject.

                    


                    
CHARACTER

                    
                    

                        
                        
                        
                    

                    

                    

                        
                        
                        
                    

                    

                    


                    
GENERATE

                    

                        
                    

                    

                        

                            
                            
                            
                            
                        

                        
Comfy Kitchen is the official H3 Recast attention backend; PyTorch is the fallback. The workflow's ModelAttentionBackend node does not accept SageAttention.

                        

                            
SCENE REFERENCE

                            

                                
                                

                                    
No scene reference yet. Select the people to replace, then build it from the clip.

                                    

                                        
                                        
                                    

                                    

                                        
                                        
                                        
                                    

                                    
                                

                            

                            
H3 Recast conditions on ONE frame of the clip with every intended replacement already edited in. Build it automatically, or upload a frame you edited yourself. Leave people you are not replacing unedited.

                        

                        
H3 Recast swaps up to three people in one pass with the BFS Character Swap LoRA. The clip supplies motion, set, accessories and audio; the scene reference supplies faces and bodies; the caption lines are generated from the people you select. Lip sync is refined automatically before upscaling.

                    

                    

                        
                        

                            
                            
                        

                        

                            
                        

                        

                            
                        

                        

                            
                        

                        
SCAIL-2 uses the official INT8 convrot checkpoint. SAM 3.1 finds the described person on every frame, so a crossing cannot move the mask to the other person. Leave the description blank to use the selected person's appearance automatically; add clothing or hair when two people look alike. Reference label is the SAM 3.1 word for the uploaded character image (default human).

                        
SCAIL-2 replaces only the selected person. The original background, other people, camera motion and audio are preserved, and the produced video is described as a positive prompt rather than an instruction.
